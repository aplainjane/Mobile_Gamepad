# Pocket Gamepad 3.0.3 Preview

手机除了刷视频，也可以试着给电脑当一次手柄。

Pocket Gamepad 通过经典蓝牙 HID 把 Android 手机变成通用手柄，主要面向 Windows 和 Steam Input。安装到手机、完成蓝牙配对，再在 Steam 中配置按钮布局，就可以开始尝试了。

### 这一版有什么

- 双摇杆、ABXY、方向键、肩键和扳机，以及 Select / Start / Home、L3 / R3。
- 多点触控、摇杆松手回中和「复位输入」。
- 浅蓝、奶油白与粉彩配色，配套卡通图标和按钮样式。
- 移除了「输入已提交」计数、正常输入历史和「导出诊断」入口。

### 下载与使用

附件中的 `PocketGamepad-3.0.3-debug.apk` 是 **debug 签名测试包**。需要 Android 9+、手机系统支持 Bluetooth HID Device，以及带蓝牙的 Windows 电脑。无需 Root，也不需要安装本项目的电脑接收程序。

通用手柄可能需要在 Steam 设置中定义布局，并为游戏启用 Steam Input。使用时请保持 App 在前台。当前仅提供本地触感，不接收游戏震动；触屏扳机为按下 / 松开两种状态。其他手机与游戏的兼容性欢迎反馈。

首次配对方法和实机截图见[中文说明](https://github.com/aplainjane/Mobile_Gamepad/blob/main/README.md)。

### English

Pocket Gamepad turns an Android phone into a generic Bluetooth HID controller, primarily for Windows and Steam Input. Pair the phone, define the controller layout in Steam, and try it in a game.

This build includes dual sticks, the usual controller buttons, multitouch input, and a pastel cartoon interface. The submission counter, routine input history, and diagnostic export UI have been removed.

Download `PocketGamepad-3.0.3-debug.apk` from the assets. This is a **debug-signed test build**, requiring Android 9+ with Bluetooth HID Device support and a Bluetooth-capable Windows PC. No root or project-specific PC receiver is needed. Keep the app in the foreground. Haptics are local only, and touch triggers are on/off. Game and phone compatibility still varies.

See the [English README](https://github.com/aplainjane/Mobile_Gamepad/blob/main/README.en.md) for setup instructions.
