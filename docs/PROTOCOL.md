# HID 输入布局

[返回中文首页](../README.md) · [English README](../README.en.md)

当前版本通过 Android `BluetoothHidDevice` 使用经典蓝牙 HID，设备名称为 `Pocket Gamepad`。本文记录输入字段，供调试或配置映射时查阅。

## 报告格式

报告 ID 1，payload 14 字节，不把 ID 重复加入 payload。按钮占 3 字节，四个摇杆轴占 8 字节，左右扳机各 1 字节，Hat 与填充占 1 字节。

| 原始轴索引 | HID Usage | 操作 | 数值 |
|---|---|---|---|
| 0 / 1 | X / Y | 左摇杆 | 16 位有符号，-32767…32767，中心 0 |
| 2 / 3 | Z / Rx | 右摇杆 | 16 位有符号，-32767…32767，中心 0 |
| 4 / 5 | Ry / Rz | 左 / 右扳机 | 0…255，松开 0 |

这里的原始轴索引对应 Windows 通用轴排列，不是所有系统的统一承诺。摇杆采用 12% 触控死区，松手回中。扳机保留独立字段，当前触控按钮只输出全按或松开；归一化网页轴上可表现为松开 -1、按下 1。

| 按键 | 网页原始按钮索引（从 0 开始） | joy.cpl 按钮号（从 1 开始） |
|---|---|---|
| A / B / X / Y | 0 / 1 / 2 / 3 | 1 / 2 / 3 / 4 |
| L1 / R1 | 4 / 5 | 5 / 6 |
| L2 / R2 | 6 / 7 | 7 / 8 |
| Select / Start | 8 / 9 | 9 / 10 |
| L3 / R3 | 10 / 11 | 11 / 12 |
| 上 / 下 / 左 / 右 | 12 / 13 / 14 / 15 | 13 / 14 / 15 / 16 |
| Home | 16 | 17 |

扳机同时作为按钮和独立轴发送；方向键同时作为按钮和 Hat 发送，便于不同输入读取器设置映射。Hat 0…7 为从上开始的顺时针八方向，8 表示松开；相反方向相互抵消。

通用 HID 可以被 Windows 识别为真正的手柄，但浏览器未必自动提供 `standard` 映射。请按原始轴与按钮索引测试，再核对 Steam 输入布局。新布局修正了原来扳机轴夹在右摇杆轴之间、Select / Start / L3 / R3 原始按钮位置不合常见布局的问题；是否在当前电脑与游戏中正确仍需重新配对后实测。

触屏按键保留本地触感，本版不声明或处理游戏震动输出。

## 读取输入

Windows 运行 `joy.cpl` 可检查原始输入。也可在项目根目录运行以下只读脚本：

```powershell
.\tools\Test-GamepadInput.ps1 -Seconds 15
```

`tools/Test-SteamGamepad.ps1` 使用指定路径下的 SDL3 库查看设备和映射。它的映射实验只作用于脚本进程，不会更改 Steam 配置。USB 调试日志标签为 `PocketPadHID`，应用内没有日志导出入口。内部事件日志最多保留 800 条，每条消息最多 700 字符；正常触控和输入不记录历史。
